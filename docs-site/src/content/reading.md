# Reading PDFs

Folio's reader is Apple's PDFKit, the same engine as Preview. It's built for reading, not editing: there are no annotation or markup tools, and Folio never changes your PDF.

## Page display

The page display menu in the reader's header, and the **View** menu, switch between:

- **Single Page**, **Continuous Scroll**, and **Two Pages**
- **Book Mode**, which shows the first page on its own, like a cover
- **Thumbnails** (⌥⌘2), a strip of pages beside the document

**Rotate Left** and **Rotate Right** turn the view only. The file on disk stays as it was.

## Zoom

The zoom menu in the header offers fit width, fit page, and preset sizes. From the keyboard:

| Action | Shortcut |
| --- | --- |
| Actual Size | ⌘0 |
| Zoom to Fit | ⌘9 |
| Fit Whole Page | ⌥⌘9 |
| Zoom In / Zoom Out | ⌘+ / ⌘− |

## Find and go to

**Edit › Find › Find…** (⌘F) searches the document. ⌘G and ⇧⌘G move between matches. **Go › Go to Page…** (⌥⌘G) jumps to a page number, and ⌥⌘↑ / ⌥⌘↓ move one page at a time.

## Print

**File › Print…** (⌘P) prints the PDF as it is. Question bubbles are never printed.
