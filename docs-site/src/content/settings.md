# Settings and shortcuts

Open **Folio › Settings…** (⌘,).

## Settings

| Section | Setting | Default |
| --- | --- | --- |
| Library | **Folder**: where your PDFs live | `~/Documents/Folio` |
| Moodle | **Courses**: Findle's folder | Found automatically |
| Moodle | **Show in sidebar** | On |
| ChatGPT | **Attach the open PDF to new chats** | Off |
| ChatGPT | **Attach the PDF when asking about it** | On |
| ChatGPT | **Import Sign-In from a Browser…**, **Sign Out of ChatGPT…** | |
| Questions | **Show question bubbles** | On |
| Questions | **Delete All Questions…** | |
| Updates | **Check for updates automatically** | On |

Once a day, Folio checks its latest GitHub release for a new version. When there is one, it shows what's new and installs the update only if you choose **Install Update**. **Folio › Check for Updates…** checks right away.
