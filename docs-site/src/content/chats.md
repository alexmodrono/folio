# Chats and attachments

The chat panel holds up to four chats at once, each a separate chatgpt.com page. Toggle the panel with **View › Show Chat** (⇧⌘L).

## More than one chat

Choose **New Chat** (⇧⌘O) to start a fresh conversation in the active chat. To keep another conversation open beside it, open the chat's **More** menu (…) and choose **Add Chat**. Chats stack on top of each other; **Show Chats Side by Side** in the same menu lays them out in columns.

The active chat is the one you last clicked or typed in. It receives selections and attachments. Close an extra chat with the × in its header.

## Attaching the PDF

Opening a PDF never uploads it. chatgpt.com uploads a file the moment it's in the message box, even before you send, so Folio asks first:

- **New chats** show the open PDF's name with an **Attach** button. Choose **Don't Attach** to dismiss it.
- **Chat › Attach PDF** (⇧⌘A), or **Attach PDF** in a chat's **More** menu, attaches it at any time.
- **Asking about a selection or page** attaches the whole PDF too, so ChatGPT has the context. Turn this off in **Settings › ChatGPT › Attach the PDF when asking about it**.
- **Settings › ChatGPT › Attach the open PDF to new chats** attaches it to every new chat automatically. It's off by default.

## One upload per conversation

Folio remembers which PDFs each conversation already has, across launches, and checks the conversation before attaching. Asking several questions about the same document in one chat uploads it once.

## Reload

If a chat stops responding, choose **Reload** from its **More** menu. Your conversation is saved on chatgpt.com, so nothing is lost.
