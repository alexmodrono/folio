# Your library

Folio keeps your PDFs in an ordinary folder, `~/Documents/Folio` by default. There's no database or import step that hides files from Finder: what you see in Folio is what's in the folder.

## Add PDFs

- Drag PDFs onto the library window.
- Choose **File › Import PDFs…** (⇧⌘I). The files are copied into the current folder, and the originals stay put.
- Choose **File › Open…** (⌘O) to read a PDF from anywhere without copying it.

Files you add to the folder in Finder appear in Folio right away.

## Organize

Choose **File › New Folder** (⇧⌘N) to make a folder. Right-click a document to rename it, show it in Finder, or **Add to Favorites** (⌘D). The **Favorites** tab on the home screen lists the ones you've marked.

The home screen shows documents as a grid or a list, sorted the way you choose.

## Move the library

In **Settings › Library**, choose **Change…** next to **Folder** to point Folio at another folder, such as one in iCloud Drive. Folio doesn't move the existing files.

## Moodle courses

If you use [Findle](https://github.com/alexmodrono/Findle), your synced Moodle courses appear under **Moodle** in the sidebar. They're read-only in Folio. See [Moodle courses](/moodle/).
