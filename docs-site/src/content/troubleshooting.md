# Troubleshooting

Most problems come from chatgpt.com changing, a sign-in expiring, or a file that hasn't downloaded yet. If none of this helps, choose **Help › Report a Problem…** to open a prefilled GitHub issue.

## "Folio can't find ChatGPT's message box"

chatgpt.com changes its page from time to time. When Folio can't find the parts it needs, the chat shows a notice:

- **Can't find the message box**: Folio can't add your PDF or selections. You can still use ChatGPT in the panel normally.
- **Can't fully work with this version of ChatGPT**: selections are pasted as plain quoted text instead of chips.

Try **Reload** from the chat's **More** menu. If the notice stays, check for a Folio update and use **Report a Problem** in the notice.

## The sign-in import fails

- **Safari** needs Full Disk Access. Choose **Open Privacy Settings**, turn on Folio, and try again.
- **Chromium browsers** need your Mac password once, to use the browser's keychain item. If you chose **Deny**, try the import again.
- **Expired sign-in**: open chatgpt.com in that browser, then import again.

You can always choose **Sign In Manually** instead. See [Sign in to ChatGPT](/sign-in/).

## The PDF uploaded twice, or not at all

Folio checks the conversation before attaching, and chatgpt.com renames repeats like `notes(2).pdf`. If a PDF is missing, choose **Chat › Attach PDF** (⇧⌘A). If you'd rather never attach automatically, turn off both attach settings in **Settings › ChatGPT**. See [Chats and attachments](/chats/).

## Attachments are refused

What you can attach depends on your ChatGPT plan and its limits on file size and count. Folio can't change those. Ask about a selection with the attach setting off to send just the text.

## A Moodle file won't open

Course files from Findle may not be downloaded yet. Right-click and choose **Download**, or open Findle and check that it's syncing. See [Moodle courses](/moodle/).

## Bubbles are missing

Check **View › Question Bubbles**. Bubbles appear only for messages you sent with a quoted selection or page, and they follow the file by its location. Rename or move PDFs inside Folio to keep their bubbles; a PDF moved in Finder loses them.
