Privacy

Last updated November 10, 2026

Folio has no accounts, no servers, no analytics and no tracking. Everything Folio stores stays on your Mac. The sections below list each case where something leaves your Mac, and the one case where Folio reads data from another app.

The chat panel

The chat panel is chatgpt.com in a web view, signed in with your own ChatGPT account. What you type, attach and send there goes to OpenAI and is covered by OpenAI's privacy policy and terms, the same as using chatgpt.com in a browser.

Opening a PDF doesn't upload it. A new chat offers the open PDF with an Attach button; it's uploaded only when you click Attach, ask about a selection or page (you can turn that off in Settings), or turn on auto-attach. chatgpt.com uploads a file as soon as it's in the message box, even before you send. Folio never sends a message itself; you always press send.

Importing your sign-in

Optionally, Folio can reuse the ChatGPT sign-in from a browser you already use. If you choose this, Folio reads only the chatgpt.com and OpenAI sign-in cookies from the browser you pick, on your Mac. macOS first asks you to allow access to that browser's keychain item; Safari also needs Full Disk Access. The cookies are copied only into Folio's own web view storage and are not sent anywhere else.

Question bubbles

When you ask about a page, Folio remembers what you asked and on which page, so it can show a bubble there later. This is saved on your Mac in ~/Library/Application Support/Folio/questions.json. Folio never modifies your PDFs.

Update check

Once a day, Folio asks GitHub's public API (api.github.com) for information about the latest release. The request carries nothing that identifies you beyond what any web request does, such as your IP address. You can turn this off in Settings.

Reporting a problem

Help > Report a Problem opens a pre-filled GitHub issue in your browser with the app version, the macOS version and recent lines from Folio's log. Nothing is sent until you review the issue and submit it yourself on GitHub.

Contact

Questions about privacy: open an issue on GitHub.
